Adaptive Sensor Fusion for UAV Navigation

Learning-Based Adaptive Fusion of Absolute Localization and Dead-Reckoning for Multi Sensor UAV Navigation — keeping a reliable position estimate when absolute positioning becomes degraded or unavailable.

overview

Project Description

UAVs typically rely on absolute localization sources such as GNSS for position. When those sources are degraded, jammed or lost, the vehicle has to fall back on dead-reckoning — integrating its own motion sensors — which drifts over time.

This thesis studies how a learning-based approach can adaptively decide how much to trust each source at every moment, combining absolute localization and dead-reckoning from multiple sensors into a single, more robust navigation estimate.
