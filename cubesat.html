CubeSat Telemetry System on FPGA

Design and implementation of a CubeSat telemetry system on FPGA, handling onboard sensor data acquisition, CCSDS-compliant frame formatting, and downlink transmission logic entirely in reconfigurable hardware.

VHDL FPGA CCSDS CubeSat Telemetry Digital Design
overview

Project Description

The goal of this thesis is to design and implement a telemetry subsystem for a CubeSat entirely on FPGA fabric, replacing a conventional microcontroller-based telemetry chain with dedicated, reconfigurable hardware logic.

The system collects housekeeping and payload sensor data on board, packages it into standardised telemetry frames, and prepares it for downlink — following the CCSDS telemetry framing standard used across real spacecraft missions.

design flow

Development Flow

01
Requirements & standard study — reviewing the CCSDS telemetry framing standard and defining the telemetry data model for a representative CubeSat mission.
02
Module design in VHDL — implementing the acquisition, framing, buffering, and transmission blocks as independent, testable entities.
03
Simulation & verification — validating each module and the full pipeline against expected CCSDS frame output using testbenches.
04
FPGA implementation — synthesising and deploying the design to target hardware for functional testing.
